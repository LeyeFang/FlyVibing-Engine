# 测试需知（Test/Application/Editor）

> 2026-10-05 整理：**规范以 `Doc/Dev/test_protocol.md` 为准**；本文件是编辑器 UI 测试的速查补充。

## 三个运行入口

| 档位 | 命令 |
|---|---|
| core 批量回归 | `python Utils/Dev/test_runner.py`（`--only` / `--exclude` / `--json` / `--list`） |
| UI 场景回放（gui） | `python Test/Application/Editor/ui_scenario.py Test/Application/Editor/scenarios/<name>.py`（`--preview` 交互预览） |
| 实机 E2E（live） | `e2e_*.py` 脚本 / `engine-editor-cli`（需编辑器运行中） |

## 两个底座

- **`_ui_boot.py`（UiBoot）**：最小编辑器引导 — EditorHost 身份注册 SceneManager、全部 5 个控制器、主线面板、隐藏窗口可截图、`io.set_ini_filename("")` 禁持久化。
- **`scenarios/*.py`**：声明式场景（`NAME` + `run(ctx)`）；`ctx` = frames / snapshot / expect / key / mouse_move / click / ctrl / panel。
  快照 = glReadPixels 后缓冲（**swap 前**）→ PNG，含完整 ImGui 界面（隐藏窗口同样可拍）。
  现有场景：`panels_smoke` / `menu_smoke` / `node_editor_smoke`。

## 速查

- 面板与控制器注入：`ControllerRegistry.register(NAME_X, Mock)` + 结束 `ControllerRegistry.reset()`（Mock 见 `Test/Helpers/MockControllers.py`）。
- 需要 `EditorHost.scene` 时：`SceneManager.Init(EditorHost); EditorHost.scene = SceneManager._state_for("EditorHost")`（`_ui_boot` 已内置）。
- **禁止**：直接注册 GLFW 回调（走 `InputPipeline`）；写仓库路径（写盘只用 `MGE_TEST_TMP`）；生成/依赖 `imgui.ini`。
- 判定契约：末行 `RESULT: ...`；失败行 `[FAIL]` 前缀。
